# 🎬 Telegram Movies & Series Bot

A Telegram bot that acts as a searchable library for movies and TV series, helping users discover, search, and get recommendations — all directly inside Telegram.

The bot lets users search a catalog of movies and series, browse details, and receive suggestions based on their interests.

## ✨ Features

- 🔍 **Search** — Find movies and series by title.
- 🎞️ **Movies & Series Library** — A catalog covering both films and TV shows.
- 💡 **Suggestions** — Get recommendations for movies and series to watch.
- 📄 **Details View** — Browse information about each title.
- 🤖 **Full Telegram Integration** — Everything works right inside the Telegram chat.
- 🗂️ **Organized Catalog** — Structured library for easy browsing and discovery.
- ⚡ **Fast & Simple** — Lightweight search and suggestion flow for a smooth user experience.
